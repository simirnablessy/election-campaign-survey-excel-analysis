# Election Campaign Survey Analysis 2026 – Excel Dashboard

## Problem Statement
Analyse call-centre survey data to understand call performance, agent productivity and voter survey responses during an election campaign.

## Tools Used
- Microsoft Excel (pivot tables, charts, dashboard layout)

## Dashboard
![Dashboard](dashboard.png)

## What the Dashboard Shows
- 67,640 total calls handled by 25 agents across 3 queues
- Call distribution by mode (manual, predictive, progressive, redial)
- Dialer status (answered, no answer, abandoned, busy, congestion)
- Total calls and average call time by agent
- Peak calling times
- Survey responses on party preference and MLA voting intent across 6 parties

## Key Insights
- Predictive mode accounted for the largest share of calls.
- Most calls ended as "No Answer", so call timing and contact rates are the main area to improve.
- Average call time was fairly consistent across agents.

## What I Learned
- Analysing large call-log datasets in Excel
- Presenting operational and survey data in one dashboard
